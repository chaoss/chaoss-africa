# CHAOSS Africa Technical Writers Focus Group

## About
This subgroup supports contributors interested in documentation quality, technical writing, and documentation-driven onboarding across CHAOSS projects.

## What this group works on
- Documentation audits and improvements
- Contributor guides and onboarding content
- Technical writing programs and challenges

## How to join
1. Introduce yourself in `#chaoss-africa` on Slack and mention you want to join the Technical Writers group.
2. Review open documentation issues in this repository.
3. Start with one improvement PR (clarity, structure, or link fixes).

## Suggested first tasks
- Improve one existing markdown page for clarity and consistency.
- Fix typos, formatting, or broken links in docs.
- Add a short "how to contribute" note to an under-documented page.
