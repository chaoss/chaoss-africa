# CHAOSS Africa Developers Focus Group

## About
This subgroup supports contributors who want to work on software, tooling, and technical implementation tasks in the CHAOSS ecosystem.

## What this group works on
- Ongoing developer projects: [Project list](https://docs.google.com/document/d/1B4O0Li1ZG-QvIAG-qR1WBdHc3hVhJnBeS6_lPdhKc9A/edit)

- Developer onboarding and code contribution support

## How to join
1. Introduce yourself in `#chaoss-africa` on Slack and mention you want to join the Developers group.
2. Review open GitHub issues and comment on one you want to work on.
3. Start with a small contribution and request feedback early.

## Suggested first tasks
- Fix a small documentation typo or broken link in this repository.
- Pick one beginner-friendly issue and submit a PR.
- Help review and test an open contributor PR.
